Moores law ends means, that the compute power of the hardware (the bottom), so the physical part of computing douples every 2 years. this came to end end, because transistors cant be made smaller anymore. This means we need to make the speed up by the "top" wich means better algorithms, better hardware architecture or better software. for software it is important to use all the power a modern chip can produce, so the software runs efficient and uses the possible power the hardware can handle, for example use all threads, write cache friendly and fill out the pipelines or use efficient memory/cache transactions. In the Algorithms it can be done by using the best possible algorith to solve a proplem. easy example is to using merge sort instead of insertion sort. It is also possible to use other algorithms that are faster on parallel hardware than seriel hardware or to find new algorithms like machine learning and compute Hardware architecture means to use explicit crafted hardware for efficent works, like tpus, gpus, npus etc. so each chip has its own specialized field for its own purpose, wich removes the overhead a generall purpose cpu would have.
